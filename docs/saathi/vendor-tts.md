# Vendor TTS transport foundation

Internal factories in `openbot/server/src/self-hosted/vendor-tts.ts` implement the existing `TextToSpeechProvider` contract for Sarvam `bulbul:v3` and ElevenLabs `eleven_v3`. They are disabled by default and remain unregistered with the website/fixture registry. Configuring a model or passing a voice ID does not grant public audio access, voice rights or spend permission.

Each invocation requires an explicit operator-selected model/voice, its own server key, `allowLiveRequests: true`, literal processing consent, a cancellation signal and an enabled locale. Defaults enable en-IN/hi-IN/ta-IN; ml-IN/kn-IN require explicit selection and have no measured fluency evidence. Text is trimmed and limited to 500 JavaScript string units; longer replies require a separately reviewed composition policy. No extra model summary call, cloning, retries, provider fallback or redirects occur.

## Wire and audio boundaries

Sarvam receives JSON `text`, `language_code`, `model`, `speaker`, `speech_sample_rate: 24000` and `output_audio_codec: wav` at the fixed text-to-speech endpoint, authenticated only with `api-subscription-key`. A bounded JSON envelope must contain exactly one canonical base64 WAV. Duration comes from actual PCM16 WAV headers, not a provider estimate. Unexpected codecs, malformed chunks, alignment, oversized or overlong audio fail closed. This is bounded WAV inspection, not a general transcoder. The returned sample rate is inspected; no resampling or guarantee that the vendor honored the requested rate is implied. [Official Sarvam API reference](https://docs.sarvam.ai/api-reference/text-to-speech/convert).

ElevenLabs receives an explicit restricted voice path, `model_id`, text and ISO language code. It requests `pcm_24000`, with `xi-api-key` only. Its documented signed little-endian PCM16 bytes are wrapped in a canonical 24kHz mono WAV without changing samples. Only `audio/pcm` and `application/octet-stream` are accepted; MP3 and big-endian `audio/L16` are rejected. Logging is denied by default; an access/retention rejection is never retried with logging enabled. The provider documents logging opt-out as enterprise-dependent. Explicit operator `providerLogging: allow` is separate. [Official ElevenLabs API reference](https://elevenlabs.io/docs/api-reference/text-to-speech/convert), [audio formats](https://elevenlabs.io/docs/overview/capabilities/text-to-speech).

The shared HTTP reader caps STT JSON at its unchanged 128,000-byte default, TTS JSON at 2,700,000 bytes including the base64 envelope, and ElevenLabs PCM at 1,999,956 bytes so the WAV stays within 2MB. Inspected audio is at most 60 seconds; the byte ceiling may impose a shorter duration. Actual streaming bytes and declared content length are checked. Deadline/parent cancellation aborts the transport and cancels the reader; a transport ignoring abort cannot hold the caller indefinitely. Raw vendor errors, text and keys are not logged or returned in error messages.

## Evidence and pending work

All tests inject mocked HTTP and generated tone/silence bytes. `source.mode=live` identifies the vendor transport contract, and `isSpeech=true` identifies the requested TTS operation; neither proves real provider access, audible speech, language correctness, voice identity or consented language evaluation. Output `language` is the requested locale, not independently detected audio language. Confirm critical names, dates and amounts before any consequential action. Sarvam retention controls and independent deletion are unverified.
