# Vendor STT transport foundation

Continue the PRD voice work independently while one Meta planning-test approval is pending. Branch codex/vendor-stt-adapters stacks on PR15. Implement two provider-neutral STT factories for Sarvam (explicit saaras:v3 or saaras:v4) and ElevenLabs (explicit scribe_v2), grounded in official REST docs. They are disabled by default and are not wired to public HTTP or the fixture-only registry. No new credential, live request, private recording, migration or deployment.

First add strict bounded PCM16 RIFF/WAV metadata validation (1–2 channels, verified sample rate/alignment, duration, size and chunk bounds); reuse generated tone fixtures solely as synthetic bytes. Vendor STT accepts at most29 seconds (stricter than the shared60-second media ceiling for Sarvam REST),2MB, explicit consent and a valid abort signal. No OGG/Opus decoder/transcoder or public upload claim.

Use fixed HTTPS endpoints/credential headers, multipart file/model/language fields, one attempt, bounded JSON and deadline/abort with no redirects/fallback or body/error logging. Normalize transcript/declared dominant language and confidence=null; language probability is not transcription confidence. Unknown/missing language must not silently become the user's hint; preserve text/code-mixing without translating it. Model/language availability and real fluency remain unverified until consented live evaluation.

TDD increments: WAV parser red/green; vendor header/model/file/language normalization tests with mocked HTTP only; input/consent/unsupported model/language, oversized/invalid response, credentials, error redaction, timeout/abort and no retry. Run focused Bun suite/server types and unchanged frozen Linux test-type gate, audited bundle/packed regressions. Use existing Zod/Bun/fetch, no new dependency. Live speech budget/owned media consent-retention and actual Sarvam/ElevenLabs TTS are subsequent work, not completed by transport factories. Keep existing public speech off.

Official sources: https://docs.sarvam.ai/api-reference/speech-to-text/transcribe and https://elevenlabs.io/docs/api-reference/speech-to-text/convert .
